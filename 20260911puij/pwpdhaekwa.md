# 凝心聚力，共谋高质量发展

> 更新时间：2026-09-11 (UTC+8)

**高质量发展·专题会议**

谋定而后动，知止而有得。为全面贯彻落实市委、市政府和市卫健委关于推动公立医院高质量发展的决策部署要求，加快推进我院高质量发展项目进度，12月22日，南宁市妇幼保健院在综合大楼20楼小会议室召开高质量发展项目工作专题会议。会议由医院副院长庞智东主持，医院领导班子、高质量专班各小组组长、副组长和相关成员参加。

**工作完成情况**

WORK SUMMARY REPORT

会议现场

**01********绩效目标完成情况<<<<**

会上，庞智东副院长首先通报南宁市区域母婴安全保障能力建设项目1-11月绩效目标完成情况。针对目前绩效指标完成情况做出分析，并提出绩效目标要求。其次解读“南宁市妇幼保健院高质量发展项目工作专班管理制度”，要求专班各工作小组严格执行专班制度各项规章制度，以制度建设为抓手，夯实专班管理基础。同时传达了上级部门文件精神，并提出工作要求：**一是**统筹做好项目整体推进，继续优化调整专班组织架构，充实专班力量；二是要求各工作小组要进一步完善、细化工作流程，优化小组工作方案，明确目标任务；**三是**要求挂图作战，做好倒排进度，紧盯目标抓进度，提高工作效率。四是要求进一步完善南宁市区域母婴安全保障能力建设项目指标数据，为高质量发展项目绩效目标提供科学的数据支撑。

**02********工作开展情况<<<<**

各工作小组副组长依次汇报前期开展工作进展情况，下一步工作计划并提出意见建议和存在困难。在汇报过程中，针对各工作小组在开展高质量发展工作过程中存在的难题和问题，院领导班子现场给予了反馈和解答，对暂时无法解决的难题，要求进行记录，会后责任科室要对接帮忙解决。

**03********资金使用情况<<<<**

医院总会计师姚明健就医院高质量发展资金使用情况做了通报，传达上级部门对高质量发展专项资金使用要求。要求**一是**专班做好资金统筹规划，集中资金突出重点；**二是**优化具体工作措施，提前谋划好明年资金使用明细和方向；**三是**要求各工作小组要善于总结，并及时反思整改、修订工作方案，调整工作思路，善于整理数据，成效的取得要用数据说话。

**工作部署**

WORK DEPLOYMENT

**何宁宇院长作工作部署**

医院院长何宁宇做高质量发展项目工作部署安排。他强调：**一是**高质量发展专班成员要提高政治站位，强化大局意识、责任意识，解放思想；**二是**要突出我院“区域母婴安全保障能力建设项目项目”的改革性、示范性，诠释“示范性”的实际内涵，完善和丰富“区域”的工作内容，推动实现项目建设目标 。**三是**要求高度重视，专班各小组成员明确工作职责，各司其职，落实挂图作战，加快推动项目落地见效。**四是**强调做好项目整体协调推进。持续深化区域母婴安全保障能力建设，扩大市县乡区域母婴安全能力建设工作范围，形成制度和体系，通过“走出去，请进来”等多种途径加强基础医疗机构和上级医疗机构的互动交流，同时借鉴外省经验做法，持续完善区域母婴市县乡体系建设，达到提高市县乡三级妇幼医疗机构危重孕产妇和新生儿救治成功率的目标；**五是**要加强组织协调，互联互通。专班各工作小组要发挥统筹协调作用，加强沟通、信息共享，确保项目取得实效，完成项目指标。

**蒋武书记作总结发言**

最后，医院党委书记蒋武做会议总结发言，**一是**明确赞成院长的意见，她表示高质量发展工作是一项改革性工作，任重道远，各工作小组一定要以高度的责任感、使命感，完成医院高质量发展项目工作目标。**二是**强调加大高质量发展项目宣传，形成系列宣传，善于创新，转变观念，各部门通力合作， 营造浓厚氛围。
